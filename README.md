# 微信 mmtls 协议实现

## 项目简介

这是一个基于 Go 语言实现的微信 mmtls（Modified TLS）协议客户端库。mmtls 是微信基于 TLS 1.3 草案开发的自定义安全传输协议，用于微信客户端与服务器之间的加密通信。

本项目实现了与微信服务器的完整 TLS 握手流程，包括密钥交换、签名验证、会话管理等核心功能。

## 项目作用

### 主要功能

1. **TLS 1.3 握手实现**
   - 完整实现 TLS 1.3 握手协议流程
   - 支持 ECDH 密钥交换（P-256 椭圆曲线）
   - 实现基于 HKDF 的密钥派生机制

2. **会话管理**
   - 支持完整握手（1-RTT ECDHE）
   - 支持 PSK 会话恢复（0-RTT PSK）
   - 会话信息持久化存储

3. **安全特性**
   - ECDSA 数字签名验证
   - AES-128-GCM 加密通信
   - HMAC-SHA256 完整性校验
   - 序列号防重放保护

4. **详细日志输出**
   - 完整的握手过程日志
   - 每个步骤的执行状态
   - 便于调试和协议研究

### 应用场景

- **协议研究**：学习和研究 TLS 1.3 和微信 mmtls 协议实现
- **安全分析**：了解微信通信协议的加密机制
- **技术实验**：用于网络协议和安全技术的实验性研究

## 技术栈

- **编程语言**: Go 1.15+
- **加密算法**: 
  - AES-128-GCM

## 如何运行

### 环境要求

- Go 1.15 或更高版本
- 能够访问 `dns.weixin.qq.com:443` 的网络环境

### 安装依赖

```bash
go mod download
```

### 运行方式

#### 方法一：直接运行（推荐）

```bash
go run main.go
```

#### 方法二：编译后运行

```bash
# 编译项目
go build -o mmtls.exe .

# Windows 运行
.\mmtls.exe

# Linux/Mac 运行
./mmtls
```

### 运行流程

1. **首次运行**
   - 程序会连接到 `dns.weixin.qq.com:443`
   - 执行完整的 TLS 握手流程
   - 成功后生成 `session` 文件保存会话信息
   - 输出详细的握手过程日志

2. **再次运行**
   - 检测到 `session` 文件后
   - 使用 PSK 会话恢复模式
   - 加快握手速度（0-RTT PSK）

## 握手流程说明

程序实现了完整的 TLS 1.3 握手流程，包括以下步骤：

1. **连接建立** - 建立与微信服务器的 TCP 连接
2. **ClientHello** - 发送客户端问候消息，包含支持的密码套件和扩展
3. **ServerHello** - 接收服务器问候消息和服务器公钥
4. **密钥交换** - 通过 ECDH 算法计算共享密钥
5. **密钥派生** - 使用 HKDF 派生握手加密密钥
6. **签名验证** - 验证服务器的 ECDSA 数字签名
7. **会话票据** - 接收并保存服务器发放的会话票据
8. **PSK 密钥派生** - 派生 PSK 访问和刷新密钥
9. **ServerFinished** - 接收并验证服务器完成消息
10. **ClientFinished** - 发送客户端完成消息
11. **应用密钥派生** - 派生应用数据传输密钥
12. **握手完成** - 握手成功，可以开始加密通信
